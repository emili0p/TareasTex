\subsection{Actividad 3: Perceptrón XOR}

A diferencia de las compuertas \texttt{AND}, \texttt{OR} y \texttt{NAND}, la compuerta \texttt{XOR} no es linealmente separable, por lo que no puede ser implementada mediante un único perceptrón. Para resolver este problema es necesario combinar varios perceptrones en una pequeña red neuronal.

En esta actividad se utilizaron tres perceptrones. Los dos primeros fueron entrenados para representar las compuertas \texttt{OR} y \texttt{NAND}. Posteriormente, las salidas de estos perceptrones se emplearon como entradas de un tercer perceptrón configurado como una compuerta \texttt{AND}. De esta manera se implementa la siguiente identidad lógica:

\[
\texttt{XOR}(A,B)=\text{AND}(\texttt{OR}(A,B),\texttt{NAND}(A,B))
\]
El procedimiento consiste en evaluar primero las entradas mediante los perceptrones \texttt{OR} y \texttt{NAND}. Las salidas obtenidas son utilizadas como entradas del perceptrón \texttt{AND}, el cual genera el resultado final correspondiente a la compuerta \texttt{XOR}. Esta arquitectura demuestra cómo la combinación de perceptrones permite resolver problemas que un único perceptrón no puede representar debido a la naturaleza no linealmente separable de la función.

\subsection{Actividad 4: Clasificación del conjunto de datos Iris}

En esta actividad se desarrolló un modelo de clasificación supervisada utilizando una red neuronal para resolver el problema de identificación de especies de flores del conjunto de datos \textit{Iris}. Este conjunto de datos es uno de los más utilizados en el área del aprendizaje automático debido a que constituye un problema de clasificación multiclase relativamente sencillo, lo que permite comprender el funcionamiento de las redes neuronales y evaluar su capacidad para aprender patrones presentes en los datos.

El conjunto de datos Iris está conformado por 150 muestras pertenecientes a tres especies de flores: \textit{Iris setosa}, \textit{Iris versicolor} e \textit{Iris virginica}. Cada muestra está descrita mediante cuatro características numéricas: longitud del sépalo, ancho del sépalo, longitud del pétalo y ancho del pétalo. A partir de estas características, el objetivo del modelo consiste en determinar correctamente la especie a la que pertenece cada flor.

Para la implementación del modelo fue necesario realizar una etapa de preprocesamiento de los datos. En esta fase se cargó el conjunto de datos, se separaron las variables de entrada y la variable objetivo, y posteriormente se dividió la información en conjuntos de entrenamiento y prueba. Este procedimiento permite entrenar la red neuronal con una parte de los datos y evaluar su capacidad de generalización utilizando información que no fue observada durante el entrenamiento.

Posteriormente, se diseñó una red neuronal de tipo \textit{feedforward}, conformada por una capa de entrada que recibe las cuatro características del conjunto de datos, una o más capas ocultas encargadas de extraer relaciones no lineales entre las variables y una capa de salida responsable de realizar la clasificación entre las tres especies de flores. Durante el entrenamiento, la red ajusta iterativamente sus pesos mediante el algoritmo de retropropagación del error (\textit{Backpropagation}) y un optimizador basado en descenso del gradiente, minimizando la función de pérdida hasta obtener una clasificación con la mayor precisión posible.

Finalmente, una vez concluido el entrenamiento, el modelo fue evaluado utilizando el conjunto de prueba con el propósito de medir su desempeño. Los resultados obtenidos permiten analizar la capacidad de la red neuronal para reconocer patrones presentes en el conjunto de datos y clasificar correctamente nuevas muestras, demostrando la aplicación práctica de las redes neuronales artificiales en problemas de clasificación supervisada.

\subsection{Actividad 5: Actualización manual de los pesos de un perceptrón}

En esta actividad se realizó el cálculo manual de la salida de un perceptrón y la actualización de sus pesos utilizando la regla de aprendizaje del perceptrón. El objetivo fue comprender el funcionamiento interno del algoritmo antes de implementarlo mediante programación.

Se parte de los siguientes valores iniciales:

\[
x_0 = 1,\qquad x_1 = -1.5,\qquad x_2 = 0
\]

\[
w_0 = -0.5,\qquad
w_1 = 1,\qquad
w_2 = -1
\]

con una salida esperada

\[
y = 1.
\]

En primer lugar, se calcula la entrada neta del perceptrón:

\[
z = w_0x_0 + w_1x_1 + w_2x_2
\]

Sustituyendo los valores:

\[
z = (-0.5)(1) + (1)(-1.5) + (-1)(0)
\]

\[
z = -0.5 -1.5 = -2
\]

Aplicando la función de activación escalón:

\[
f(z)=f(-2)=-1
\]

Como la salida obtenida es diferente de la salida esperada, es necesario actualizar los pesos utilizando la regla de aprendizaje:

\[
\Delta w_i = \eta\,y\,x_i
\]

donde la tasa de aprendizaje es

\[
\eta = 2.
\]

Los incrementos calculados son:

\[
\Delta w_0 = 2(1)(1)=2
\]

\[
\Delta w_1 = 2(1)(-1.5)=-3
\]

\[
\Delta w_2 = 2(1)(0)=0
\]

Los nuevos pesos quedan definidos como:

\[
w_0=-0.5+2=1.5
\]

\[
w_1=1-3=-2
\]

\[
w_2=-1+0=-1
\]

Finalmente, se verifica nuevamente la salida utilizando los pesos actualizados:

\[
z=(1.5)(1)+(-2)(-1.5)+(-1)(0)
\]

\[
z=1.5+3=4.5
\]

Por lo tanto,

\[
f(z)=f(4.5)=1,
\]

obteniéndose ahora la salida esperada. Esto demuestra que, después de una iteración de aprendizaje, el perceptrón corrige sus pesos para clasificar correctamente el patrón de entrada.

\subsection{Actividad 6: Gradiente Descendiente y una red neuronal artificial}
\subsubsection*{Parámetros Iniciales del Problema}
Basado en el ejercicio numérico del video, definimos las siguientes condiciones y variables del sistema:
\begin{itemize}
    \item \textbf{Entradas:} $x_1 = 2$, $x_2 = 1$
    \item \textbf{Pesos iniciales (Época 1):} $w_1 = -0.5$, $w_2 = 0.5$
    \item \textbf{Sesgo (Bias):} $b = 0$
    \item \textbf{Valor esperado (Target):} $y = 0.6$
    \item \textbf{Tasa de aprendizaje (Learning rate):} $\eta = 0.4$
    \item \textbf{Función de activación:} Sigmoide $\sigma(h) = \frac{1}{1 + e^{-h}}$
\end{itemize}

\subsubsection*{Fórmulas Utilizadas}
\begin{enumerate}
    \item \textbf{Suma neta:} $h = w_1x_1 + w_2x_2 + b$
    \item \textbf{Salida predicha:} $\hat{y} = \sigma(h) = \frac{1}{1 + e^{-h}}$
    \item \textbf{Error residual simple:} $e_{residual} = y - \hat{y}$
    \item \textbf{Error cuadrático (Loss):} $E = (y - \hat{y})^2$
    \item \textbf{Término de error del gradiente:} $\delta = (y - \hat{y}) \cdot \hat{y} \cdot (1 - \hat{y})$
    \item \textbf{Incremento de pesos:} $\Delta w_i = \eta \cdot \delta \cdot x_i$
    \item \textbf{Actualización de pesos:} $w_i^{nuevo} = w_i + \Delta w_i$
\end{enumerate}

\subsubsection*{Desarrollo de las Épocas}

\paragraph{Época 1}
\begin{itemize}
    \item \textbf{Forward Pass:}
    \[ h = (-0.5 \times 2) + (0.5 \times 1) = -1.0 + 0.5 = -0.5 \]
    \[ \hat{y} = \sigma(-0.5) = 0.377 \]
    \item \textbf{Cálculo de Errores:}
    \[ e_{residual} = 0.6 - 0.377 = 0.223 \]
    \[ E = (0.223)^2 = 0.049 \]
    \item \textbf{Gradiente y Actualización:}
    \[ \delta = 0.223 \times 0.377 \times (1 - 0.377) = 0.052 \]
    \[ \Delta w_1 = 0.4 \times 0.052 \times 2 = 0.041 \implies w_1^{nuevo} = -0.5 + 0.041 = -0.459 \]
    \[ \Delta w_2 = 0.4 \times 0.052 \times 1 = 0.020 \implies w_2^{nuevo} = 0.5 + 0.020 = 0.520 \]
\end{itemize}

\paragraph{Época 2}
\begin{itemize}
    \item \textbf{Forward Pass:}
    \[ h = (-0.459 \times 2) + (0.520 \times 1) = -0.918 + 0.520 = -0.398 \]
    \[ \hat{y} = \sigma(-0.398) = 0.401 \]
    \item \textbf{Cálculo de Errores:}
    \[ e_{residual} = 0.6 - 0.401 = 0.199 \]
    \[ E = (0.199)^2 = 0.0396 \]
    \item \textbf{Gradiente y Actualización:}
    \[ \delta = 0.199 \times 0.401 \times (1 - 0.401) = 0.0478 \]
    \[ \Delta w_1 = 0.4 \times 0.0478 \times 2 = 0.0382 \implies w_1^{nuevo} = -0.459 + 0.0382 = -0.421 \]
    \[ \Delta w_2 = 0.4 \times 0.0478 \times 1 = 0.0191 \implies w_2^{nuevo} = 0.520 + 0.0191 = 0.539 \]
\end{itemize}

\paragraph{Época 3}
\begin{itemize}
    \item \textbf{Forward Pass:}
    \[ h = (-0.421 \times 2) + (0.539 \times 1) = -0.842 + 0.539 = -0.303 \]
    \[ \hat{y} = \sigma(-0.303) = 0.425 \]
    \item \textbf{Cálculo de Errores:}
    \[ e_{residual} = 0.6 - 0.425 = 0.175 \]
    \[ E = (0.175)^2 = 0.0306 \]
    \item \textbf{Gradiente y Actualización:}
    \[ \delta = 0.175 \times 0.425 \times (1 - 0.425) = 0.0428 \]
    \[ \Delta w_1 = 0.4 \times 0.0428 \times 2 = 0.0342 \implies w_1^{nuevo} = -0.421 + 0.0342 = -0.387 \]
    \[ \Delta w_2 = 0.4 \times 0.0428 \times 1 = 0.0171 \implies w_2^{nuevo} = 0.539 + 0.0171 = 0.556 \]
\end{itemize}

\subsection{Actividad 7: Forward Pass y BackPropagation en Red Neuronal Artificial}

La tangente hiperbólica ($\tanh$) es una función de activación utilizada en redes neuronales que mapea los valores de entrada al intervalo $(-1,1)$. Su principal ventaja respecto a la sigmoide es que está centrada en cero, lo que facilita la convergencia del gradiente en capas profundas. Su derivada $f'(z)=1-f(z)^2$ permite calcular el gradiente del error durante el proceso de retropropagación. A continuación se presenta un ejercicio numérico que aplica el algoritmo de gradiente descendente con una neurona con activación $\tanh$.

\paragraph{Datos Iniciales}
\begin{itemize}
    \item Entradas: $x_{1} = 0.5$, $x_{2} = -0.2$
    \item Pesos iniciales: $w_{0} = 0.4$, $w_{1} = 0.3$
    \item Tasa de aprendizaje ($\eta$): $0.5$
    \item Valor objetivo ($y$): $1.0$
    \item Función de activación (Tangente Hiperbólica): 
    \[ f(z) = \tanh(z) = \frac{e^{z}-e^{-z}}{e^{z}+e^{-z}} \]
    \item Derivada de $\tanh$: $f'(z) = 1 - f^2$
\end{itemize}

\paragraph{Demostración de la Derivada}
Utilizando la regla del cociente $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$:
\[ \frac{d}{dz}\left[\frac{e^{z}-e^{-z}}{e^{z}+e^{-z}}\right] = \frac{(e^{z}+e^{-z})(e^{z}+e^{-z}) - (e^{z}-e^{-z})(e^{z}-e^{-z})}{(e^{z}+e^{-z})^2} \]
\[ = \frac{(e^{z}+e^{-z})^2 - (e^{z}-e^{-z})^2}{(e^{z}+e^{-z})^2} = 1 - \frac{(e^{z}-e^{-z})^2}{(e^{z}+e^{-z})^2} = 1 - f^2 \]

\paragraph{Época 1}

\subparagraph{1. Calcular Salida / Forward Pass}
\[ z = w_{0}x_{1} + w_{1}x_{2} \]
\[ z = (0.4)(0.5) + (0.3)(-0.2) = 0.2 + (-0.06) = 0.14 \]
\[ \hat{y} = f(z) = \tanh(0.14) \Rightarrow 0.139 \]

\subparagraph{2. Determinar el Error / LOSS}
\[ E = (y - \hat{y})^2 = (1.0 - 0.139)^2 = 0.741 \]

\subparagraph{3. Modificar los Pesos}
\textbf{3.1 Término de error ($\delta$):}
\[ \delta = (y - \hat{y}) \cdot f'(z) = (y - \hat{y})(1 - \hat{y}^2) \]
\[ \delta = (1.0 - 0.139)(1 - 0.139^2) = (0.861)(1 - 0.019) \]
\[ \delta = (0.861)(0.981) = 0.844 \]

\textbf{3.2 Calcular el incremento ($\Delta w_i = \eta \cdot \delta \cdot x_i$):}
\[ \Delta w_{0} = 0.5 \cdot 0.844 \cdot 0.5 = 0.211 \]
\[ \Delta w_{1} = 0.5 \cdot 0.844 \cdot (-0.2) = -0.0844 \]

\textbf{3.3 Actualizar Pesos ($w_i = w_i + \Delta w_i$):}
\[ w_{0} = 0.4 + 0.211 = 0.611 \]
\[ w_{1} = 0.3 + (-0.0844) = 0.216 \]

\subparagraph{4. Estimar la Nueva Salida}
\[ z = 0.611(0.5) + 0.216(-0.2) = 0.3055 - 0.0432 = 0.2623 \]
\[ \hat{y} = \tanh(0.2623) = 0.2564 \]

\subparagraph{5. Nuevo Error}
\[ E = (1.0 - 0.2564)^2 = 0.5529 \]

\paragraph{Época 2}

\subparagraph{1. Calcular Salida / Forward Pass} (omitimos por brevedad, ya se calculó al final de la época anterior)

\subparagraph{2. Modificar los Pesos}
\textbf{2.1 Término de error ($\delta$):}
\[ \delta = (1.0 - 0.2564)(1 - 0.2564^2) = (0.7436)(1 - 0.0658) \]
\[ \delta = (0.7436)(0.9342) \approx 0.6924 \]

\textbf{2.2 Calcular el incremento:}
\[ \Delta w_{0} = 0.5 \cdot 0.6924 \cdot 0.5 = 0.1731 \]

\textbf{2.3 Actualizar Pesos:}

\subparagraph{4. Nuevo Error}

\subsection{Actividad 8: Carga y Visualización del Dataset CelebA con TensorFlow}

\subsection{Actividad 9: Regresión Lineal con TensorFlow y Gradiente Descendente}

La regresión lineal es uno de los modelos más fundamentales en aprendizaje automático. Su objetivo es encontrar una relación lineal entre una variable de entrada $x$ y una variable de salida $y$, de forma que se pueda predecir $y$ a partir de $x$ mediante la ecuación $\hat{y} = w x + b$, donde $w$ es la pendiente y $b$ la intersección (sesgo). El aprendizaje consiste en ajustar $w$ y $b$ para minimizar el error cuadrático medio entre las predicciones y los valores reales.

En esta actividad se implementa manualmente el algoritmo de **gradiente descendente** para entrenar un modelo de regresión lineal utilizando TensorFlow. En lugar de usar la API de alto nivel (`keras`), se definen las variables manualmente y se calculan los gradientes con `tf.GradientTape`, lo que permite comprender en profundidad el mecanismo de optimización. Además, se realizan múltiples entrenamientos con diferentes inicializaciones e hiperparámetros para observar la robustez del método.

\subsubsection*{Preparación de los Datos}

Se generan datos sintéticos con una tendencia lineal aproximada, pero con cierta dispersión para simular ruido. Los valores de entrada $x$ son números del 0 al 9, y los valores de salida $y$ se definen manualmente para que sigan una tendencia creciente, con algunas desviaciones. Los datos se normalizan restando la media y dividiendo por la desviación típica, para facilitar la convergencia del gradiente descendente.

A continuación se muestra el código de preparación de datos y de definición del modelo.

\begin{lstlisting}[language=Python, caption={Preparación de datos y definición del modelo de regresión lineal}, label={lst:regresion1}]
import tensorflow as tf
import numpy as np 
import matplotlib.pyplot as plt

# Datos sintéticos
x_train = np.arange(10).reshape((10,1))
y_train = np.array([1.0, 1.3, 3.1, 2.0, 5.0, 6.3,
                    6.6, 7.4, 8.0, 5.0])

# Normalización
x_train_norm = (x_train - np.mean(x_train))/np.std(x_train)

# Creación de dataset de TensorFlow
ds_train_orig = tf.data.Dataset.from_tensor_slices(
    (tf.cast(x_train_norm, tf.float32),
     tf.cast(y_train, tf.float32))
)

# Definición del modelo
class Modelo(tf.keras.Model):
    def __init__(self):
        super(Modelo, self).__init__()
        self.w = tf.Variable(0.0, name='pesos')
        self.b = tf.Variable(0.0, name='bias')

    def call(self, x):
        return self.w * x + self.b

# Función de pérdida (error cuadrático medio)
def loss_fn(y_true, y_pred):
    return tf.reduce_mean(tf.square(y_true - y_pred))

# Función de entrenamiento (un paso de gradiente descendente)
def train(model, inputs, outputs, learning_rate):
    with tf.GradientTape() as tape:
        predictions = model(inputs)
        loss = loss_fn(outputs, predictions)
    dW, dB = tape.gradient(loss, [model.w, model.b])
    model.w.assign_sub(learning_rate * dW)
    model.b.assign_sub(learning_rate * dB)
    return loss
\end{lstlisting}

El modelo se define como una clase que hereda de `tf.keras.Model` y contiene dos variables entrenables: $w$ y $b$. La función `train` utiliza `GradientTape` para registrar las operaciones y calcular automáticamente los gradientes de la pérdida con respecto a los parámetros, actualizándolos mediante la regla del gradiente descendente.

\subsubsection*{Entrenamiento y Resultados}

Se ejecutan cinco entrenamientos independientes, cada uno con una inicialización aleatoria de los pesos (entre -5 y 5) y con una tasa de aprendizaje y número de épocas aleatorios. Esto permite observar cómo el algoritmo converge a soluciones similares a pesar de las diferentes condiciones iniciales. Durante cada entrenamiento se registran la evolución de los pesos, el sesgo y la pérdida.

\begin{lstlisting}[language=Python, caption={Entrenamiento con múltiples inicializaciones}, label={lst:regresion2}]
import random

random.seed(8)
tf.random.set_seed(1)

resultados = []

for j in range(5):
    # Nuevo modelo e inicialización aleatoria
    model = Modelo()
    model.w.assign(random.uniform(-5, 5))
    model.b.assign(random.uniform(-5, 5))

    # Hiperparámetros aleatorios
    learning_rate = random.uniform(0.0005, 0.01)
    num_epochs = random.randint(150, 250)
    batch_size = 1

    steps_per_epoch = int(np.ceil(len(y_train) / batch_size))
    ds = ds_train_orig.shuffle(buffer_size=len(y_train))
    ds = ds.repeat(count=None)
    ds = ds.batch(batch_size)

    Ws, Bs, Losses = [], [], []

    for i, batch in enumerate(ds):
        if i >= steps_per_epoch * num_epochs:
            break
        Ws.append(model.w.numpy())
        Bs.append(model.b.numpy())
        bx, by = batch
        loss_val = loss_fn(by, model(bx))
        Losses.append(loss_val.numpy())
        train(model, bx, by, learning_rate)

        if i % 100 == 0:
            print(f"Epoch {int(i/steps_per_epoch):4d} Step {i:4d} Loss {loss_val:.4f}")

    resultados.append({
        "modelo": model,
        "Ws": Ws,
        "Bs": Bs,
        "Losses": Losses,
        "lr": learning_rate,
        "epochs": num_epochs
    })
    print(f"Parámetros finales -> w={model.w.numpy():.3f}, b={model.b.numpy():.3f}, lr={learning_rate:.5f}, epochs={num_epochs}")
\end{lstlisting}

Los resultados muestran que en todos los casos el modelo converge a valores de $w$ cercanos a 2.07 y $b$ cercanos a 4.56, lo que indica que la solución es estable y no depende en exceso de la inicialización. \subsubsection*{Preparación de los Datos}

\begin{enumerate}

    \item Las características numéricas (GPA, Test, Assignment) se normalizan con \texttt{MinMaxScaler} para escalar los valores al rango [0,1].

\end{enumerate}

\subsection{Actividad 16: Mejorando el modelo base del ejercicio MNIST fashion}

\subsection{Actividad 22: Naive Forecast con Dataset Mercantil}

En esta actividad se aborda el problema de pronóstico de ventas diarias de un producto específico utilizando un conjunto de datos mercantil. Se aplica el método de pronóstico \textit{Naive} (o método ingenuo), que asume que el valor futuro será igual al último valor observado. El objetivo es evaluar la efectividad de este método simple en un contexto de series temporales con pocos datos históricos.

\subsubsection*{Metodología Experimental}

El conjunto de datos está compuesto por varios archivos CSV que contienen registros de movimientos de inventario. Los datos se combinan en un único DataFrame y se filtran para conservar únicamente los registros de ventas (Tipmovinv = 12). Posteriormente, se identifican los productos más vendidos y se selecciona el producto con mayor volumen de ventas para el análisis.

Para el producto elegido (07TOPUBR), se realiza un análisis de ventas diarias. Los datos disponibles son escasos: solo dos registros de ventas en el período comprendido entre octubre de 2025 y abril de 2026. Se divide el conjunto en entrenamiento (primer día) y validación (último día). El pronóstico \textit{Naive} consiste en utilizar el valor del último día de entrenamiento como predicción para el día de validación.

Se calculan métricas de error para evaluar el desempeño del pronóstico:

\begin{itemize}
    \item \textbf{Error Cuadrático Medio (MSE)}: Mide el promedio de los errores al cuadrado.
    \item \textbf{Error Absoluto Medio (MAE)}: Mide el promedio de los errores absolutos.
\end{itemize}

\subsubsection*{Resultados}

El producto seleccionado, 07TOPUBR, presenta dos registros de ventas: 363,000 unidades el 20 de octubre de 2025 y 3,850 unidades el 30 de abril de 2026. El pronóstico \textit{Naive} para el 30 de abril de 2026 es de 363,000 unidades, lo que resulta en un error absoluto de 359,150 unidades.

\subsubsection*{Análisis}

El pronóstico \textit{Naive} presenta un error muy elevado, con un MAE de 359,150 unidades, lo que representa una desviación significativa respecto al valor real (3,850 unidades). Esto se debe a la naturaleza esporádica de las ventas del producto y a la falta de un patrón temporal consistente en los datos históricos.

El método \textit{Naive} es adecuado para series temporales con comportamiento estable o tendencia constante, pero en este caso, con solo dos puntos de datos separados por varios meses, el método no puede capturar la estacionalidad o la variabilidad del comportamiento de ventas.

La alta magnitud del MSE (128,988,722,500.00) refleja la gran diferencia entre el pronóstico y el valor real, amplificada por el cuadrado del error.

\subsubsection*{Conclusiones}

Este estudio experimental permite extraer las siguientes conclusiones:

\begin{itemize}
    \item El método \textit{Naive} es extremadamente sensible a la cantidad y calidad de los datos históricos disponibles.
    \item Para productos con ventas esporádicas o con pocos datos históricos, el pronóstico \textit{Naive} no es recomendable, ya que produce errores muy grandes.
    \item La alta variabilidad en las ventas del producto 07TOPUBR sugiere que se necesitan métodos más avanzados (como modelos de suavizado exponencial o ARIMA) para capturar patrones estacionales o tendencias.
    \item La evaluación con métricas como MSE y MAE permite cuantificar el error y comparar diferentes métodos de pronóstico.
\end{itemize}

Como trabajo futuro, se recomienda:

\begin{itemize}
    \item Ampliar el conjunto de datos incluyendo más períodos históricos para cada producto.
    \item Aplicar métodos de pronóstico más sofisticados (Promedio Móvil, Suavizado Exponencial, ARIMA) y comparar su desempeño con el método Naive.
    \item Realizar un análisis de estacionalidad para identificar patrones cíclicos en las ventas.
    \item Implementar un sistema de pronóstico automático que seleccione el mejor modelo en función de las características de cada serie temporal.
\end{itemize}

def parse_fecha(fecha_str):
    try:
        return datetime.strptime(fecha_str, '%d/%m/%y')
    except:
        pass
    try:
        return datetime.strptime(fecha_str, '%d/%m/%Y')
    except:
        return pd.NaT

prod_ventas['Fecha'] = prod_ventas['Fecmovinv'].apply(parse_fecha)
prod_ventas = prod_ventas.dropna(subset=['Fecha']).sort_values('Fecha')

ventas_diarias = prod_ventas.groupby('Fecha')['Cant'].sum().reset_index()
